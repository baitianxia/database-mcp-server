数据库助手（当前支持 MySQL）

这是给 Claude Code 使用的本地 database MCP 服务。当前适配器是 MySQL，产品身份和工具契约保持通用。

开始使用

  1. 请先把 ZIP 完整解压到普通目录，再在本窗口所在目录运行 INSTALL.cmd 完成首次安装或升级；不要从压缩包预览窗口直接启动。
  2. 运行 CONFIGURE.cmd，从模板创建并填写 %USERPROFILE%\database-mcp-server\config\settings.json。
  3. INSTALL.cmd 会使用当前用户已有的 Claude Code 自动注册用户级 database-mcp；安装完成后重启 Claude Code，在任意项目运行 /mcp 确认，再调用 database_config_status 或 database_environment_list。

配置文件可以包含明文用户名和密码，只应让当前 Windows 用户读取。密码会被服务脱敏，不会出现在状态、错误或工具响应中；请不要把配置文件复制到 Git、压缩包或共享目录。

如果安装失败，窗口会保留并显示原始错误；INSTALL.cmd 的本次日志保存在 %TEMP%\database-mcp-server\INSTALL-*.log，直接运行 INSTALL.ps1 时才使用 %USERPROFILE%\database-mcp-server\logs\install.log。

修改配置

编辑后调用 database_config_reload 即可生效，无需重启 Claude Code。没有 defaultEnvironment 时，数据库工具必须显式传环境名；UNINSTALL.cmd 默认保留配置。

如果当前用户不能运行 claude，安装器会停止并显示原因，不会安装或下载 Claude Code。完整说明请阅读同目录的 README.md；清单和 SHA256SUMS.txt 用于检查制品完整性。
